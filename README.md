# Theme #50 Contribution Matrix (proposal)

Working draft of a coverage x witness matrix proposed for [FG-TIDA Theme #50](https://github.com/FG-TIDA/themes/issues/50) (Completeness and Coordination of FG-TIDA Pre-standardization Activities).

- `Theme50-matrix-external.html` - the matrix draft (Chinese, HTML)
- `matrix.json` - machine-readable matrix data (rows ordered by witness, not mechanism)

Status: proposal for discussion, not a consensus output. Contributions welcome via the Theme #50 issue thread.
